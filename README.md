## 🚀 Featured Project

### SaaS Workspace Analytics Dashboard

- Built a full-stack analytics platform using Spring Boot, React, and PostgreSQL.
- Implemented JWT authentication, role-based access control, and protected REST APIs.
- Integrated AI-powered admin insights using the Gemini API.
- Containerized the application using Docker and Docker Compose.
- Deployed on AWS EC2 using Nginx as a reverse proxy.
- Configured CI/CD using GitHub Actions.
